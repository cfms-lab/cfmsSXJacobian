# Poisson 힘 게이트 — 2010 년 논문의 Poisson 조건을 명세 한 줄로 쓴다

상태: **GO (2026-11-13, 2 차) — Q0 – Q7 모두 통과.** 1 차는 Q6 의 b 하나가 미달이라 NO-GO 였다(1.26e-12, 기준 1e-12). 판정 뒤
진단으로 그것이 b 가 거의 0 이 되는 표본 하나의 반올림임을 확인했고, 사용자 결정으로 b 의 척도만 바꾼 2 차 판정을 했다
(아래 「2 차 기준」 — 새 척도의 값을 알고 한 판정이다).
사용자가 「새 힘을 정의해 시험하는 순서」를 물은 뒤 이 명세와 게이트를 만들라고 했다. 기준은 Provot 전단 게이트
(`docs/GATE_PROVOT_SHEAR.md`)의 것을 옮겨 실행 전에 적었다 — 기준 표 자체를 따로 확인받지는 않았다.

## 무엇을 보이나

Sul · Kim · Park, 「Simulation of Fabric Poisson Effect in Semi-implicit Particle-based Method」, Textile Research Journal 80(8):
760–766 (2010) 의 Poisson 힘은 엔진에 없는 힘이다(378d20c 에는 `SDEMaterialProperty.h` 의 주석 처리된 `Kp` 한 줄뿐). 이 게이트는
그 힘의 조건 함수를 명세 `codegen/specs/sul_poisson.py` 한 줄로 쓰고, 거기서 맞는 `C · ∇C · ∇²C` 와 조립이 나오는지를 본다.
곧 「새 힘을 넣는 순서」의 첫 구간(명세 → 생성 → Mathematica · 유한차분 → 조립 → SXMesh 루프)이다.

## 원문에서 읽은 것

읽은 판은 PDF 를 글로 옮긴 것(`IJ_2010_TRJ_Poisson.md`, 리포 밖)이라 수식이 줄마다 끊겨 있다. 아래는 조각을 이어 읽은 것이다.

- 식 (6) `C^P = log(|w_u| · |w_v|^β) = log|w_u| + β log|w_v|`. `w_u` · `w_v` 는 Baraff–Witkin 의 것(인장 명세와 같다). 원문은
  삼각형 넓이를 1 로 둔다. `|w|` 가 0 이 아니라 특이점이 없다는 것이 이 꼴을 고른 까닭이다.
- β 는 재질 값이다. 식 (6) 대로면 β = 1 · 0 · −1 이 넓이 보존 · 가로 변형 없음 · 가로로 같이 늘어남(그림 1 의 세 경우)이다.
  원하는 Poisson 비 ν₀ ≥ 0 에는 β = 2ν₀ 를 쓴다. ν₀ < 0 쪽 식은 옮긴 글에서 깨져 읽지 못했다 — 명세는 β 를 그대로 받으므로
  그 대응에 기대지 않는다.
- 식 (7) `∂C/∂x_i = (w_u/|w_u|²) · ∂w_u/∂x_i + β (w_v/|w_v|²) · ∂w_v/∂x_i`.
- 식 (8) `∂²C/∂x_i∂x_j = (1/|w_u|²)(I − 2ŵ_uŵ_uᵀ) ∂w_u/∂x_j ∂w_u/∂x_i + β (1/|w_v|²)(I − 2ŵ_vŵ_vᵀ) ∂w_v/∂x_j ∂w_v/∂x_i`
  (`w` 가 좌표의 1 차식이라 `∂²w = 0`).
- 식 (9) `f^P = −k_P C ∇C`. `k_P` 는 다른 힘에 대한 Poisson 힘의 세기이고 β 와 따로다.
- 검증은 단축 인장 시뮬레이션(ν = 0.3 · 0 · −0.3, 시간 간격 30 ms)을 ABAQUS 유한요소 해석과 견준 것이다. 이 게이트는 그것을 다시 하지 않는다.

## 명세

```
C = √a (log|w_u| + β log|w_v|),   a = uv 넓이
```

- 삼각형 스텐실 · 성분 1. 스텐실 값 = 쉬는 uv 6 칸(`pUV`) + **Poisson 계수 β 1 칸(`pBeta`)**. β 를 삼각형마다 받으므로 재질이
  곳마다 달라도 된다.
- `√a` 를 곱한다 — 인장 · 전단 명세와 같은 처방이고(사용자 결정 2026-11-13), 에너지 `½k|C|²` 가 넓이에 비례한다. 원문(a = 1)의 힘에
  `a` 를 곱한 것과 같다.
- **`IMPLICIT_TENSION` 을 켜지 않는다.** `∇²(log|w|) = (I − 2ŵŵᵀ)/|w|²` 는 고윳값이 +1 · +1 · −1 (÷ |w|²) 인 부정치 행렬이라,
  인장 C > 0 판의 근거(`∇²C` 가 준정부호)가 없다. 강성 판은 정확판 `EvalImplicit` 과 Gauss–Newton `EvalImplicitGN` 둘이다
  (기본은 GN — `docs/GATE_POISSON_INTEGRATION.md` 뒤 사용자 결정 2026-11-13).
- `w_u` · `w_v` 를 `ctx.stage` 로 표시한다.

**생성기를 한 줄 고친다.** `log` 가 `std::log` 가 아니라 `log(std::sqrt(…))` 로 나온다(아래 「실행 전에 한 것」). 출력기에
`_print_log` 를 더한다 — 인장 때 `Abs` → `std::fabs`, Bridson 때 `sin` · `cos` 를 더한 것과 같은 일이다. 기존 명세는 `log` 를 쓰지
않으므로 출력이 그대로여야 한다(Q0).

**실행 전에 한 것(판정 밖, 리포 밖 임시 폴더).** 같은 조건 함수를 `pBeta` 로 받는 시험 명세로

- 텐서 꼴 보기 `sxview.view()` 가 그대로 되고, 화면의 식이 성분 미분과 값 8.0e-15 · 1 차 7.8e-16 · 2 차 1.3e-15 로 맞았다(50 표본,
  SymPy 끼리의 비교다). 화면의 식은 원문 식 (7) · (8) 과 같은 꼴이었다.
- 생성기를 고치지 않고 모든 변형이 생성됐다 — 평탄판 연산 437 · 단계판 357 · `EvalImplicit` 714 · GN 226, 엔진 꼴 443 · 237 · 190.
  컴파일하지 않았고 값은 아무것도 견주지 않았다.

## 판정 뒤 진단 — Q6 b 는 b 가 거의 0 이 되는 표본 하나의 반올림이다 (판정 밖)

`tests/diag_poisson_b.cpp` → `results/diag_poisson_b.json`.

성분이 하나라 Gauss–Newton 의 b 는 스칼라 하나에 `∇C` 를 곱한 것이다: `b_GN = −h s ∇C`, `s = k C + (kd + h k) Ċ`. `k C` 와
`(kd + h k) Ċ` 가 서로 지우거나 `Ċ = Σ_a ∇_a C v_a` 안에서 항들이 지우면 `|b|` 가 작아지고, 판정이 쓴 상대 오차
`max|Δb| / max|b_기준|` 가 그만큼 커진다. 그래서 표본마다 지움 = `|s| / S`, `S = k|C| + (kd + h k) Σ_a |∇_a C v_a|` 와 지움을 뺀 척도의
오차 `max|Δb| / (h S max|∇C|)` 를 쟀다.

|---|---|---|
| 상대 오차 최대 · 중앙 | 1.26e-12 · 3.8e-16 | 4.5e-13 · 4.9e-16 |
| 최대인 표본 | 971 번 | 971 번 |
| 그 표본의 지움 `|s| / S` | 2.0e-4 | 2.0e-4 |

## 이 게이트가 말하지 않는 것

- (그 뒤 `docs/GATE_POISSON_INTEGRATION.md` 가 아래 첫 두 항목을 봤다 — 단축 인장에서 예측한 평형에 가고, 권고는 GN 이다.)
- **천을 적분했을 때 Poisson 비가 얼마로 나오는가.** 원문의 단축 인장 검증에 해당하는 것이고, 이 리포의 적분 하네스
  (`tests/test_integration.cpp`)에는 클램프를 움직이는 장면이 없다.
- 강성 판(정확판 대 GN)의 안정 · 시간. 인장 · 전단처럼 적분 비교로 정할 일이다.
- 엔진 꼴 변형(`EvalEngine*`)의 값 — 생성만 되고 L1(`tests/test_link_l1.cpp`)에는 넣지 않았다. 엔진 연결도 하지 않는다.
- 퇴화 가드(넓이 · 길이 0)는 명세 밖이다.

**다음 판정의 재료 — 유도이고, 메시로 재지 않았다**(요소 하나의 스칼라 에너지를 숫자로 최소화한 값과는 넷째 자리까지 맞는다)**.** 인장(`C = √a(|w| − 1)`, 강성 `k_T`)과 이 힘(강성 `k_P`)만 있고 변형률이 작고
고르며 늘리는 방향이 u · v 축일 때, 가로 변형률을 에너지 최소로 풀면 `r = k_P / k_T` 로

```
u 방향으로 늘릴 때  ν = r β / (1 + r β²),      v 방향으로 늘릴 때  ν = r β / (1 + r)
```

곧 β 만으로 Poisson 비가 정해지지 않고 `k_P / k_T` 에 따라 달라지며, 늘리는 방향에 따라 다르다. `r = 1` 이면 v 방향은 `β / 2` 라
원문의 `β = 2ν₀` 와 맞고, u 방향은 `ν₀ = 0.3` 에서 0.44 가 된다. 단축 인장 적분 시험을 짤 때 견줄 값이다.
