# 인장 C > 0 판 게이트 — 늘어난 쪽의 기하 강성만 남긴 조립 `EvalImplicitTension`

판정 기준은 실행 전에 고정한다(볼트 규칙 §1, 2026-11-13). **결과(2026-11-13): 정의 P0 – P2 PASS, 적분 (가′) · (나′) · (다′) ·
(라′) 모두 넘음 → 권고는 인장의 기본 강성을 `EvalImplicitTension` 으로.** 쓸 수 있는 회가 60 짝 중 정확판 31 에서 52 로
늘었고, 정확판이 버티던 곳은 하나도 잃지 않았으며, 시간은 정확판의 1.003 배다. 아래 「결과」.
사용자가 권고대로 인장 기본을 이 판으로 바꿨다(2026-11-13, 아래 「결정」).

## 왜

시간 적분 비교(`docs/GATE_INTEGRATION.md`)에서 인장의 두 판은 반대쪽에서 실패했다.

- **정확판**(`EvalImplicit`): 눌린 곳(C < 0)의 `C∇²C` 가 음이라 요소 A 가 부정치가 된다. 굽힘이 부드러우면 h ≥ 1/120 에서
  PCG 가 깨진다.
- **GN 판**(`EvalImplicitGN`): 늘어난 곳(C > 0)의 `C∇²C`(가로 방향 기하 강성, 양)를 버린다. 그 몫이 사실상 명시적으로
  적분되어, 정확판이 버티는 곳에서 발산한다(인장 (가) 위반 22).

그래서 **늘어난 쪽의 기하 강성만 남기고 눌린 쪽은 버리는 판**을 생성기가 내게 하고, (1) 정의대로인지, (2) 언제나 양의
준정부호인지, (3) 같은 천 적분에서 정확판보다 나은지를 본다. 사용자 요청(2026-11-13). 용수철 모형에서 압축 쪽 가로 강성
`k(1 − L0/L)` 을 0 으로 자르는 흔한 처방과 같은 생각이다.

## 변형의 정의

성분 c 마다 `s_c = k C_c + kd Ċ_c`, `Ċ_c = ∇C_c · v`, `α = h kd + h² k`, `C⁺ = max(C, 0)`.

| | `EvalImplicit` (정확) | `EvalImplicitGN` | **`EvalImplicitTension`** |
|---|---|---|---|
| 힘 `f + d` | `−Σ s_c ∇C_c` | 같다 | 같다 |
| `∂f/∂x` 의 탄성 몫 `K` | `−k Σ (∇C_c∇C_cᵀ + C_c ∇²C_c)` | `−k Σ ∇C_c∇C_cᵀ` | `−k Σ (∇C_c∇C_cᵀ + C_c⁺ ∇²C_c)` |
| `∂d/∂x` | `−kd Σ Ċ_c ∇²C_c` | 0 | 0 |
| `∂d/∂v` | `−kd Σ ∇C_c∇C_cᵀ` | 같다 | 같다 |
| `A` (위 삼각) | `α Σ ∇C∇Cᵀ + h² Σ s_c ∇²C_c` | `α Σ ∇C∇Cᵀ` | `α Σ ∇C∇Cᵀ + h² k Σ C_c⁺ ∇²C_c` |
| `b` | `h(f + d) + h²(K + ∂d/∂x) v` | `h(f + d) + h² K_GN v` | `h(f + d) + h² K_T v` |

- 세 판 모두 `b = −Σ h k C_c ∇C_c − A v` 꼴로 정리된다. 그래서 생성기에서는 정확판 조립의 계수
  `β_c = h² s_c` 를 `β_c = h² k C_c⁺` 로 바꾸는 것뿐이다. 힘은 바뀌지 않고 Jacobian 만 바뀐다.
- **감쇠의 `∂d/∂x` 는 버린다.** `Ċ < 0` 이면 그 몫이 음이라 준정부호를 깬다. 이 시나리오에서 `kd / k = 1e-4 s` 라 작다.
  `kd = 0` 이면 늘어난 성분(C > 0)에서 정확판과, 눌린 성분(C ≤ 0)에서 GN 판과 같다.
- **언제나 양의 준정부호다 — `∇²C_c` 가 양의 준정부호인 조건에서.** 인장 `C_c = √a (|w_c| − 1)` 은 좌표의 1 차식 `w_c` 의
  길이라 볼록하고, `∇²C_c` 가 준정부호다. 그래서 `A_T` 는 계수가 0 이상인 준정부호 행렬의 합이다.
- **명세가 고른다.** 명세에 `IMPLICIT_TENSION = True` 를 적었을 때만 생성기가 이 함수를 낸다. 지금은 인장 명세
  (`baraff_stretch.py`)만이다. 전단(`C = √a w_u·w_v`)은 `∇²C` 가 부정치이고 C 의 부호가 늘어남을 뜻하지 않는다. 굽힘의
  부호는 접힌 방향이다. 그래서 둘에는 쓰지 않는다.
- 이 판은 어떤 힘의 미분도 아니다(근사 Jacobian). 그래서 시간 적분 비교의 I0(유한차분 대조)는 적용하지 않는다.

### 적분 — `docs/GATE_INTEGRATION.md` 와 같은 시나리오 · 적분기 · 시간 간격

인장 ∈ {E, G, T} × 전단 ∈ {E, G} × 굽힘 ∈ {Baraff E, Baraff G, Bridson E, Bridson G, 엔진 Bridson} × 굽힘 k ∈ {1e-5, 1e-3}
× h ∈ {1/120, 1/60, 1/30} = 180 회(엔진 리포가 없으면 144 회). E · G 회는 시간 적분 비교와 같은 계산이다(결정적).

**쓸 수 있음** = 시간 적분 비교의 「안정」(발산 · PCG 깨짐 · 상한 · 음의 대각 없음) **그리고 최대 변형률 ≤ 0.25**.
변형률 조건은 이 게이트에서 새로 둔다. 시간 적분 비교에서 「안정」이지만 변형률이 1.3 – 3.3 인 회(인장 GN · 전단 GN ·
뻣뻣함 · h = 1/120)가 있었다. 정확판 인장의 안정한 회는 모두 0.03 – 0.09 였다.

짝 = 같은 전단 · 굽힘 · 굽힘 k · h 에서 인장만 E 와 T(60 짝, 엔진이 없으면 48).

| 명제 | 내용 | 기준 |
|---|---|---|
| (가′) 안정 | E 가 쓸 수 있으면 T 도 쓸 수 있다 | 위반 0 |
| (나′) 차이 | h ∈ {1/60, 1/30} 에서 T_h · E_h · E_{h/2} 가 모두 쓸 수 있는 짝마다 `D(T_h, E_h) ≤ D(E_h, E_{h/2})`(D 는 시간 적분 비교와 같다) | 견준 짝 ≥ 1 이고 위반 0 |

**권고 규칙**: (가′) · (나′) · (다′) · (라′) 를 모두 넘으면 인장의 기본 강성으로 `EvalImplicitTension` 을 권한다. 하나라도
못 넘으면 정확판 `EvalImplicit` 를 그대로 권한다. 기본값을 바꿀지는 사용자가 정한다.

기준을 이렇게 고른 이유.
- (다′) 의 기준 짝은 뻣뻣한 굽힘으로 둔다. 시간 적분 비교는 부드러운 굽힘 · 1/60 을 기준 짝으로 고정했다가 양쪽 모두
  불안정해 시간을 잴 수 없었다. 뻣뻣한 굽힘에서는 정확판이 안정하다. T 는 정확판과 비용이 같아(계수 하나만 다르다)
  빨라질 이유가 없으므로 「5 % 안 느림」을 본다.
- (라′) 가 이 판의 목적이다. 안정을 잃지 않는 것((가′))만으로는 정확판을 바꿀 이유가 없다.
- (나′) 의 기준은 시간 적분 비교와 같다 — 강성 판의 차이가 시간 간격을 반으로 줄인 차이보다 작아야 한다.

## 판정 뒤 — 해석

- **시간 적분 비교에서 보인 인장의 두 실패 기전이 맞았다.** 눌린 쪽의 음의 기하 강성을 버리고 늘어난 쪽을 남기면, 정확판이
  버티던 곳은 그대로 버티고 정확판이 깨지던 곳의 다수가 버틴다. 늘어난 쪽만 남겼으니 GN 처럼 발산하지도 않는다.
- 시간 적분 비교의 해석 「부드러운 천은 강성 판의 선택으로 풀 문제가 아니다」는 틀렸다. 인장 판의 선택으로 h = 1/120 은
  풀렸고, 1/60 도 굽힘 · 전단 판에 따라 풀린다. 그 판정문에 이 사실을 덧붙였다.
- 남은 실패는 정확판 전단과 Baraff 굽힘에 몰려 있다. 전단의 기본을 정확판으로 둔 근거는 시간 적분 비교의 (가) 위반 하나
  (인장 E · 엔진 굽힘 · 1/120)였다. 인장이 T 일 때 전단 GN 은 오히려 더 많은 회를 살렸다. 전단을 다시 견줄지는 사용자 몫이다.

## 결정 (사용자, 2026-11-13)

권고대로 **인장의 기본 강성을 `EvalImplicitTension` 으로 바꾼다.** 다른 힘은 그대로다 — 전단 · Baraff 굽힘 · 압축 명세는
정확판 `EvalImplicit`, Bridson 굽힘은 `EvalImplicitGN`. 코드에 기본값 장치는 없으므로 쓰는 쪽이 인장에 이 함수 이름을
고른다. 전단을 인장 T 와 함께 다시 견줄지는 정하지 않았다. 그 뒤 사용자 요청으로 다시 견줬고 — `docs/GATE_SHEAR_GN.md` —
권고대로 전단 기본도 `EvalImplicitGN` 으로 바꿨다(2026-11-13).

## 이 게이트가 말하지 않는 것

시간 적분 비교와 같다 — 충돌 · 접촉, Newton 반복, 큰 천, 다른 시나리오. 전단 · 굽힘의 강성 판은 바꾸지 않는다.
`∂d/∂x` 를 남기되 계수를 자르는 다른 판(`max(s, 0)`)은 견주지 않는다.
