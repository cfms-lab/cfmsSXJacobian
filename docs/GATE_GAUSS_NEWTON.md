# Gauss–Newton 게이트 — ∇²C 를 버린 조립 변형 `EvalImplicitGN`

판정 기준은 실행 전에 고정한다(볼트 규칙 §1, 2026-11-13). **판정: GO (2026-11-13)** — 아래 「결과」.

## 왜

Bridson 굽힘 게이트(`docs/GATE_BRIDSON.md`)에서 정확한 강성까지 내는 생성 코드(`EvalImplicit`)는 엔진 Bridson 손 코드
(`GetImpBending_Oh_SOA`)보다 3.3 배 느렸다(B8). 엔진 Jacobian 은 정확한 K 도 아니었다. 비용의 큰 몫은 ∇²C 다 — 미분만
내는 `EvalStaged` 도 엔진의 1.6 배였다. 그래서 생성기가 **같은 명세에서 ∇²C 를 쓰지 않는 조립 변형**을 함께 내면
(1) 맞는 근사인지, (2) 엔진 손 코드보다 느리지 않은지를 본다. 사용자 요청(2026-11-13).

## 변형의 정의

원문 식 (6) 의 요소 기여는 `A = −h ∂f/∂v − h² ∂f/∂x`, `b = h(f + d) + h² ∂f/∂x v` 다. 성분 c 마다 `s_c = k C_c + kd Ċ_c`,
`Ċ_c = ∇C_c · v`. 정확판(`EvalImplicit`)과 Gauss–Newton 판(`EvalImplicitGN`)은 이렇게 다르다.

| | `EvalImplicit` (정확, 감쇠는 원문 꼴) | `EvalImplicitGN` |
|---|---|---|
| 힘 `f + d` | `−Σ s_c ∇C_c` | 같다 |
| `∂f/∂x` 의 탄성 몫 `K` | `−k Σ (∇C_c∇C_cᵀ + C_c ∇²C_c)` | `−k Σ ∇C_c∇C_cᵀ` |
| `∂d/∂x` | `−kd Σ Ċ_c ∇²C_c` (원문처럼 비대칭 항은 버림) | 0 |
| `∂d/∂v` | `−kd Σ ∇C_c∇C_cᵀ` | 같다 (∇²C 가 없는 정확한 값) |
| `A` (위 삼각) | `α Σ ∇C_c∇C_cᵀ + h² Σ s_c ∇²C_c` | `α Σ ∇C_c∇C_cᵀ` |
| `b` | `h(f + d) + h²(K + ∂d/∂x) v` | `−Σ (h k C_c + α Ċ_c) ∇C_c` (= `h(f + d) + h² K_GN v`) |

`α = h kd + h² k`. 곧 **`EvalImplicitGN` = `∇²C = 0` 으로 둔 `AssembleImplicit`** 다. 힘은 바뀌지 않고 Jacobian 만 바뀐다.
`α > 0` 이면 요소 `A` 는 언제나 양의 준정부호라(계수 ≥ 0 인 외적의 합), 질량 행렬에 더한 선형계가 대칭 양의 정부호로
남는다 — 정확판의 `C ∇²C` 는 그렇지 않을 수 있다. 조건이 0 인 곳(`C = 0`)에서는 탄성 몫 K 가 정확판과 같다.

- 생성기는 단계판(`ctx.stage`)이 있는 명세에서 `EvalImplicit` 옆에 `EvalImplicitGN` 을 늘 함께 낸다. 중간 변수 공간의
  ∇²ᵤC 와 `∇²ₓu` 를 쓰지 않고, `∇C = Jᵀ ∇ᵤC` 만 만든 뒤 `A` 를 좌표 공간의 외적으로 바로 쓴다.
- 명세는 고치지 않는다. 다섯 명세(`baraff_bend` · `baraff_bend_compact` · `baraff_stretch` · `baraff_shear` · `bridson_bend`)
  모두 단계판이 있다.

## 측정 방법 변경 — 보고 항목 둘을 더함 (첫 실행 뒤, 판정 밖)

첫 실행에서 버린 몫이 표본 전체로는 O(1) 로 나왔다. 표본의 C 가 크기 때문이다(Baraff 굽힘은 `|θ − θ0| < 0.1 rad` 인
표본이 1000 개 중 18 개뿐이고, 인장 표본은 늘림 비가 0.8 – 1.3 이다). 그래서 보고에 둘을 더했다. (1) 쉬는 모양 가까이(`max|C| / 척도 < 0.1`)만 모은 탄성 몫,
(2) 음의 고윳값이 있을 때 그 크기(`|최소 고윳값| / 최대 고윳값 크기`)의 중앙값. 판정(N0 – N2)과 기준은 바꾸지 않았다.

- Gauss–Newton 판이 버리는 `C∇²C` 는 C 에 비례한다. 쉬는 모양 가까이(굽힘 0.1 rad 안, 인장 · 전단 변형률 0.1 안)에서
  탄성 몫의 5 – 7 %(중앙값), 많으면 11 – 24 % 다. 표본 전체(C 가 큼)에서는 O(1) 이다.
- 정확한 `−K/k = Σ(∇C∇Cᵀ + C∇²C)` 는 표본 대부분에서 음의 고윳값을 갖는다 — 굽힘은 거의 모두이고 크기도 최대 고윳값의

  양의 준정부호다.

## 판정 뒤 — 사용자 결정 (2026-11-13)

**Bridson 굽힘의 기본 강성은 `EvalImplicitGN` 으로 한다.** 다른 힘(Baraff 굽힘 · 압축 명세 · 인장 · 전단)은 정확판
`EvalImplicit` 를 그대로 기본으로 둔다.

- Bridson: 엔진 Jacobian 도 정확한 K 가 아닌 근사였다(B7). GN 은 그보다 빠르고(N2), 무엇을 버렸는지가 분명하며, 요소 A 가
  언제나 양의 준정부호라 엔진의 PCG 풀이기에 안전하다.
- 나머지: 속도 이득이 작거나(인장 · 전단 0.5 – 0.6) 정확판도 이미 엔진보다 빠르다(Baraff 굽힘, 엔진 비교 게이트 E4).
  작은 천을 실제로 시간 적분해 정확판 · GN 을 견준 뒤 정한다.
- 코드에 「기본값」 장치는 두지 않았다. 두 함수는 입출력이 같아 쓰는 쪽이 이름으로 고른다.
