# 인장 · 전단 게이트 — 삼각형 스텐실과 벡터 조건도 명세만으로

판정 기준은 실행 전에 고정한다(볼트 규칙 §1, 2026-11-13). **판정: GO (2026-11-13)** — 원문의 `a` 판과, 사용자 결정으로 바꾼 `√a` 판 둘 다.

## 무엇을 보이나

지금까지의 명세는 굽힘 하나였다(힌지 · 꼭짓점 4 · 성분 1 · 스텐실 값 1 칸). Baraff & Witkin (1998) §4.2 의
인장 · 전단은 세 가지가 다르다.

- 스텐실이 **삼각형**이다(꼭짓점 3 · 자유도 9).
- 인장은 **벡터 조건**이다(성분 2).
- 스텐실 값이 **여러 칸**이다(쉬는 상태 uv 6 칸).

이 셋이 생성기 · SXMesh 변수 생성 · 스텐실 모으기를 고치지 않고 명세만으로 되는지 본다. 특히 `EvalImplicit` 의
성분 여럿 길(성분마다 `A` · `b` · `f` 를 더한다)은 이번에 처음 돈다. 굽힘 게이트들은 성분이 하나였다.

생성기에서 바꾸는 것은 출력 하나뿐이다. 넓이의 절댓값 `Abs` 를 `std::fabs` 로 낸다(기본 출력은 `fabs`).
굽힘 명세에는 `Abs` 가 없어 굽힘 생성물은 바이트까지 그대로다 — `check_flat_unchanged.py`(S3)가 계속 확인한다.

## 명세

원문 §4.2 에서 곱하는 넓이만 `√a` 로 바꿨다(사용자 결정 2026-11-13, 아래). 삼각형 꼭짓점 (0, 1, 2), 쉬는 상태(패턴) 좌표 `(uᵢ, vᵢ)`.

```
(Δx₁ Δx₂) = (w_u w_v) ⎡Δu₁ Δu₂⎤      Δx₁ = x₁ − x₀,  Δu₁ = u₁ − u₀ …
                      ⎣Δv₁ Δv₂⎦
인장  C = √a (|w_u| − b_u,  |w_v| − b_v),   b_u = b_v = 1      (원문은 √a 대신 a)
전단  C = √a  w_u · w_v
a = uv 삼각형 넓이 = |Δu₁Δv₂ − Δu₂Δv₁| / 2
```

| | `codegen/specs/baraff_stretch.py` | `codegen/specs/baraff_shear.py` |
|---|---|---|
| 이름 | `BaraffStretch` | `BaraffShear` |
| 성분 | 2 | 1 |
| 스텐실 | `ppTriangles`(삼각형마다 꼭짓점 3) | 같음 |
| 스텐실 값 | `pUV`(6) = u₀ v₀ u₁ v₁ u₂ v₂ | 같음 |
| 중간 변수(`ctx.stage`) | `w_u`, `w_v`(성분 6) | 같음 |

- **스텐실 값은 쉬는 uv 그대로**다. 2 × 2 역행렬과 넓이는 명세 안에서 기호로 쓰고 생성 코드가 계산한다.
  사용자가 미리 역행렬을 만들어 두는 손 코드가 없다.
- **두 명세로 나눈다.** 원문은 인장 · 전단의 강성을 따로 두는데 `EvalImplicit` 의 계수 `{k, kd, h}` 는 명세 하나에 하나다.
- `w_u`, `w_v` 는 좌표의 1 차식이다. 그래서 `∇²ₓu = 0` 이고, `J = ∂w/∂x` 의 성분이 스텐실 값(uv)의 식이 된다.
- **`√a` 는 사용자 결정이다(2026-11-13).** 원문처럼 `a` 를 곱하면 에너지 `½k|C|²` 가 넓이의 제곱에 비례한다.
  `√a` 를 곱하면 넓이에 비례해서, 같은 천을 잘게 나눠도 에너지 밀도가 같다. 처음 판정은 원문의 `a` 로 했다(커밋 05266d0).
- `b_u = b_v = 1` 은 원문 그대로다.

엔진의 면내 힘은 다른 모형이다(Provot 스프링 · 불변량 기반 전단 등, `SDECore.h` 218 – 235). 그래서 이 게이트에서는
엔진과 견주지 않는다.

## 판정 기준 (실행 전 고정 · 2026-11-13)

- **상대오차:** 삼각형마다 모든 성분에 걸친 `max|Δ| / max|기준|` 이고, 표본 전체에서 최댓값을 잡는다.
- **`C` 오차:** 넓이로 나눈 절대오차 `|ΔC| / a` 다. `C / a` 는 「늘어난 비율 − 1」 · 「`w_u · w_v`」 라 차원이 없고,
  쉬는 모양에서 0 이라 상대오차를 쓸 수 없다. `√a` 판에서는 `|ΔC| / √a` 다(아래 「측정 방법 변경」).

| 게이트 | 기준 | 표본 |
|---|---|---|
| T1 Mathematica (`Eval`, `EvalStaged`) | `|ΔC|/a` ≤ 1e-12, `∇C` · `∇²C` 상대 ≤ 1e-10 | `results/triangles.txt` 처음 200 개 |
| T2 유한차분 (`Eval`, `EvalStaged`) | `∇C` · `∇²C` 상대 ≤ 1e-6. 중심차분, 간격 = `|x₁ − x₀|` × 1e-6, 분모 = 실제 간격 | 1000 개 |

### 측정 방법 변경 — `√a` 판 (2026-11-13)

명세가 `a` 대신 `√a` 를 곱하게 바뀌어(사용자 결정), 차원 없는 양은 `C / √a` 가 됐다. 그래서 `√a` 판의 `C` 오차는
`|ΔC| / √a` 로 잰다. 기준값(1e-12)과 다른 기준 · 표본은 그대로다. Mathematica 기준도 `√a` 로 바꿔 다시 냈다.

T4 를 1e-12 로 정한 이유: 조립 게이트에서 탄성력과 감쇠력이 상쇄하는 요소는 더하는 순서만으로도 `f + d` 가
1.6 – 1.7e-13 어긋났다(식은 맞음, `docs/GATE_ASSEMBLY.md`). 그래서 1e-13 보다 엄격하게 견주지 않기로 했다
(사용자 결정 2026-11-13). T4 가 잡으려는 것은 성분 여럿 길의 식 오류이고, 식 오류라면 상대오차가 1 의 크기로 난다.

## 표본

`model/make_triangles.py`(시드 20261113)가 1000 개를 만든다. 한 줄 = x(9) · uv(6) · v(9).

- **쉬는 uv 삼각형:**
  - 첫 변 길이 0.5 – 3 cm, 둘째 변은 첫 변의 0.5 – 1.5 배, 사잇각 30 – 150°.
  - uv 평면에서 무작위로 돌리고, ±1 m 안으로 옮긴다(패턴 좌표).
  - 절반은 v 를 뒤집어 감김 방향을 바꾼다.
- **변형:** `x = R F (uv − uv₀) + t`.
  - `F = [[s_u, γ], [0, s_v], [0, 0]]`, s_u · s_v ∈ [0.8, 1.3], γ ∈ [−0.4, 0.4].
  - R 은 무작위 회전, t 는 ±1 m.
  - 그러면 `w = R F` 다(`|w_u| = s_u`, `w_u · w_v = s_u γ`).
- **고정 표본:** 처음 4 개는 쉬는 모양(F = I) · u 방향 1.2 배 · 순수 전단 γ = 0.3 · 압축(0.85, 0.9)이다.
- **속도:** ±0.2 m/s.

Mathematica 기준은 `model/baraff_stretch_shear_ref.wl` 이다.
- 한 줄 = 인장 C(2) · g(18) · H(2 × 45) · 전단 C(1) · g(9) · H(45), 유효숫자 25.
- uv 를 40 자리로 넣고 x 에 대해 `D` 로 미분한다.
