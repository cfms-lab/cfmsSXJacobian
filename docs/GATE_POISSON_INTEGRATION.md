# Poisson 힘 단축 인장 적분 — 유효 Poisson 비가 예측대로 나오는가, 강성 판은 어느 쪽인가

상태: **2 차 (2026-11-13) — 전제 통과, (다) 예측 확인 통과(24 / 24), (가) · (나) 통과 → 권고는 Poisson 힘의 기본 강성을
`EvalImplicitGN` 으로.** 1 차는 (다) 가 16 / 24 로 미달이었다. 까닭은 물리가 아니라 「정상」의 정의였다 — 장면 U 에는 풀려 있는 강체
병진(y)이 있어 속력이 0 으로 가지 않는다. 정상의 정의만 고쳐 다시 판정했다(아래 「2 차 기준」 — 결과를 거의 알고 한 판정이다).
사용자가 권고대로 Poisson 힘의 기본 강성을 GN 판으로 정했다(2026-11-13, 아래 「결정」).
사용자 요청 「적분 시험 진행」. 기준 표를 따로 확인받지는 않았다 — 이 문서에 먼저 적고 돌렸다. 앞선 게이트
`docs/GATE_POISSON.md`(2 차 GO)가 말하지 않은 두 가지를 본다.

## 무엇을 보이나

1. **천을 적분했을 때 가로 변형이 예측한 평형으로 가는가.** 원문(Sul · Kim · Park 2010)의 검증이 단축 인장이었다. 여기서는
   균일 변형이 정확한 평형이 되는 장면을 골라, 요소 하나의 에너지에서 따로 구한 평형(Mathematica)과 견준다.
2. **Poisson 힘의 강성 판을 정확판 `EvalImplicit` 과 Gauss–Newton `EvalImplicitGN` 중 어느 쪽으로 할 것인가.** `∇²C` 가 부정치라
   인장의 C > 0 판은 없다(`docs/GATE_POISSON.md`). 인장 · 전단처럼 같은 장면을 두 판으로 적분해 버티는 회를 센다.

## 장면

- 천: u 방향 10 cm × v 방향 5 cm, 노드 21 × 11(간격 5 mm), 삼각형 400 개(인장 · 전단 적분 하네스와 같은 대각선 짜임).
  쉬는 uv 는 **안쪽 노드를 간격의 ±20 % 로 흩뜨린다**(시드 20261116, 가장자리 노드는 그대로) — 삼각형 넓이가 제각각이라야
  `√a` 가중이 틀렸을 때 힘이 서로 지우지 않는다.
- 재질(시간 적분 비교와 같다): 면밀도 0.2 kg/m², 인장 `k_T = 1000` · `kd = 0.1`(`EvalImplicitTension`), 전단 `k = 100` · `kd = 0.01`
  (`EvalImplicitGN`). 굽힘 · 중력은 없다 — 천이 평면에 머문다.
- Poisson: `k_P = r k_T`, `kd_P = 1e-4 k_P`(인장과 같은 비). `r ∈ {0.3, 1}`, `β ∈ {−0.6, 0, 0.6, 1}`.
- 늘림: `ε ∈ {0.02, 0.2, 1}`(1 = 원문의 100 %). **늘려 놓고 놓는다** — 처음 상태는 `x = (1 + ε) u`, `y = v`, 속도 0.
- **장면 U(판정)**: 양 끝(u = 0, u = 10 cm)의 노드는 x 만 고정한다(y 는 자유). 그러면 균일 변형 `x = (1 + ε) u`, `y = s_v v` 가
  정확한 평형이다 — 안쪽 노드에서는 같은 응력끼리 지우고, 자유 가장자리의 가로 응력이 0 인 `s_v` 가 평형이다.
- **장면 C(보고만)**: 양 끝의 노드를 모두 고정한다(원문의 클램프). 변형이 고르지 않아 닫힌 기준이 없다 — 가운데 단면의 폭만 잰다.
- 적분: 식 (6) 을 단계마다 한 번, 걸러진 PCG(Jacobi 전처리, `δ ≤ ε² δ₀`, ε = 1e-6, 상한 2000) — 시간 적분 비교와 같다.
  `h ∈ {1/120, 1/30}`(원문은 30 ms), T = 2 s.
- 회: 장면마다 r 2 × β 4 × ε 3 × h 2 × 판 2 = 96 회.

## 기준 평형 (독립 기준)

`model/sul_poisson_uniaxial_ref.wl` → `results/mma_ref_poisson_uniaxial.txt`. 균일 변형에서 넓이당 에너지는

```
e(s_v) = ½ k_T [(s_u − 1)² + (s_v − 1)²] + ½ k_P (log s_u + β log s_v)²,   s_u = 1 + ε
```

이고(전단은 0), `∂e/∂s_v = 0` 을 `s_v = 1` 에서 출발해 40 자리로 푼다. 생성 코드와 무관하게 손으로 쓴 식이다. 줄마다
`r β ε s_v e″/k_T 근의 수 ν_선형` 을 쓴다 — `e″` 는 극소인지, 근의 수는 `s_v ∈ [0.05, 5]` 에서 `∂e/∂s_v` 의 부호가 바뀌는 횟수다.
**`e″ ≤ 0` 이거나 근이 하나가 아닌 경우는 판정에서 빼고 보고만 한다**(기준이 하나로 정해지지 않는다).

## 용어

- **안정** = 시간 적분 비교와 같다 — 발산(속력 > 50 m/s · 유한하지 않음) · PCG 깨짐(`pAp ≤ 0`) · 상한 · 음의 대각이 한 단계도 없다.
- **정상** = 마지막 0.5 s 동안 최대 노드 속력 ≤ 1e-8 m/s.
- **도달**(장면 U) = 안정 · 정상이고, 끝 상태의 모든 삼각형에서 `||w_u| − (1 + ε)| ≤ 1e-6`, `||w_v| − s_v 기준| ≤ 1e-6`,
  `|ŵ_u · ŵ_v| ≤ 1e-6` 이며 뒤집힌 삼각형이 없다(가로로 뒤집힌 상태도 `|w_v|` 는 같으므로 따로 본다).
- **짝** = 같은 r · β · ε · h 에서 Poisson 판만 E 와 G 인 두 회. 장면 U 에 48 짝.

**유효 Poisson 비**(`ν = (1 − s_v) / ε`, 기준 평형 — 메시가 반올림까지 같은 값을 낸다)

- 곧 **이 힘에서 Poisson 비를 정하는 것은 β 하나가 아니라 `β` 와 `k_P / k_T` 의 짝이고, 늘림에 따라서도 달라진다.** 원문의 `β = 2ν₀` 는

## 이 시험이 말하지 않는 것

- 면 밖 거동(주름). 처음 상태가 정확히 평면이고 굽힘이 없어, 면 밖 성분은 끝까지 0 이다.
- 늘림을 서서히 주는 경우. 여기서는 늘려 놓고 놓는다 — ε = 1 은 첫 단계에 가로로 수십 % 를 움직여야 하는 거친 경우다.
- 시간. 엔진. 인장이 `EvalImplicitTension` 이 아닌 조합.
- v 방향으로 늘리는 경우(선형화 식 `r β / (1 + r)` 는 재지 않았다)와 비스듬한 방향.
- 중력 · 굽힘이 있는 의복 장면에서의 안정. 여기서 본 것은 평면 안의 풀림뿐이다.
